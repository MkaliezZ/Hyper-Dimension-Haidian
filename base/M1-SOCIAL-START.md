# M1 通信与论坛交付 · 扩展 v0.3.0

> **历史范围 / 兼容工具参考。** 本文记录当时里程碑，不是当前完成度或开发优先级。旧的“尚未实现”、功能上限、数据库数量及候选状态不覆盖后续版本；涉及具体命令仍须核对当前脚本和实例。当前流程以[统一开发手册](DEVELOPMENT-MANUAL.md)及本版验收为准。

这是在 M1 v0.2.0 上继续开发的独立版本，包含原 Base、M0 和 M1 的源码、模型、浏览器依赖、配置说明及验证工具。既有交付包与运行数据保留。Base 核心协议版本仍为 0.2.1。

## 先用哪个入口

| 目标                             | 入口                             |
| -------------------------------- | -------------------------------- |
| 第一次了解 Base、搭建学校        | START-HERE.md、AGENT-START.md    |
| 安装 Ubuntu 多服务后端           | M1-START.md、docs/M1.md          |
| 私信、学校与组织讨论             | 浏览器 `/social.html`            |
| 成员、邀请、审核及交接           | 浏览器 `/m1.html`                |
| 编辑 NodeBB 原帖、提交修订、回复 | 从管理台帖子点击“查看原帖与编辑” |
| 通信接口、保留策略与权限         | docs/M1-SOCIAL.md                |
| 复做本轮验收                     | evidence/m1-social/ACCEPTANCE.md |

初始化、启动仍用 `tools/m1-init.mjs` 与 `tools/m0-services.mjs`；详见 M1-START。当前开发实例是 `http://127.0.0.1:4580/m1.html`，这是本机隔离测试地址，其他机器按自己的 config.origin 打开。旧 M1 地址 4380 不自动切换。

在 ZIP 中直接 `npm start` 启动的是轻量空间示例。正式账号、私信和论坛需要按 M1 文档安装 PostgreSQL、Keycloak、Nakama、NodeBB；这些独立服务的服务器镜像不包含在源码 ZIP 中。固定版本、安装器和插件源码均在包内。

## 接手 Agent 的第一条任务

读取 AGENTS.md、M1-SOCIAL-START.md、docs/M1-SOCIAL.md。先核对现有实例和私有配置，创建备份及独立恢复实例，再更新本包插件和模块、应用追加迁移，验证后交接。不要覆盖旧包、重置用户库、复制个人 Hermes 密钥或把聊天导入接待知识库。不要为验收改变原生限流。

本轮已验证通信与原帖修订的功能链路。公网域名/TLS、真实邮件送达、实际学校权限口径与承载验收仍须在目标服务器落实；本包不将同机自动测试标成生产上线或真人验收。
