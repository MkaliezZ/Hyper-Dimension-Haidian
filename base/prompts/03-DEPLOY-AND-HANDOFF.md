# 复制给 Codex：部署和交付验收

> 执行前先读 [统一开发手册](../DEVELOPMENT-MANUAL.md) 与 [AGENTS](../AGENTS.md)。本文是分项清单；当前版本、运行模式、验证和打包以统一手册为准，保留旧包与用户数据。

请读取 AGENTS.md、docs/STARTUP.md、docs/DEPLOYMENT.md 和当前学校项目交接，在【目标环境】部署当前 Base。先备份既有数据、配置、项目和数据库；检查端口、原进程和权限，不杀不相关进程。

在普通可写目录解压或更新新版本，保留 .local 和学校项目。数据库选择与模型配置按私有模板执行，不把维护者 token 给访客。正式公网补齐 HTTPS、域名来源、校方身份和最小权限数据库用户。只跑本轮所需验证，不重复整小时验收。

最终交付：可运行包、学校项目、启动/停止/恢复说明、Hermes 与知识库配置模板、资料和素材索引、自动验证证据、截图、文件 SHA 清单及待校方核实项。区分资料模式/真实模型、概念建筑/精确复刻、自动浏览器/真人体验。对未接入的数据库服务器、未测试的机器和未发生的真实试用标记 NOT_TESTED，不模拟签字。
