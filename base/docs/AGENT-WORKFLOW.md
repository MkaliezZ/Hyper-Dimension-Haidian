**当前统一流程已集中到根目录 [DEVELOPMENT-MANUAL.md](../DEVELOPMENT-MANUAL.md)。** 本文件保留原路径，供旧链接继续使用。

- Agent/人类阅读顺序与历史判读：手册第 1–2 节。
- 图纸→解读→学校项目→可运行场景：第 5 节；详细清单 [00-BUILD-SCHOOL](../prompts/00-BUILD-SCHOOL.md)。
- 视觉升级、人物美术适配：第 6 节；正式素材由学校提供。
- 资料、Hermes 与 A2A：第 7 节。
- 共享功能开发、验证、备份、重新打包、交接：第 8–12 节。

保留稳定 ID 和共享几何；记录图纸依据、推定与未知，PDF 原件私有保存。模型输出必须在浏览器真正可运行且能通行。资料与素材需要来源/许可，学校事实不由模型编造；不修改旧包或用户数据。完整校园模式与 Base-1 示例的验证分开记录。
