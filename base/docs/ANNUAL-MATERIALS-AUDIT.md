## 范围判断

材料中的迎新、节日、招新、毕业、学习交流、志愿等由既有活动、论坛和运营引擎承接。接机、同行、住宿和室友等情境可由自愿报名、私域讨论、联系人授权与受控服务工单承接；本轮不声称提供专门的自动匹配、交通调度或批量外传个人资料系统。

原规划已将复杂金融/支付/旅行交易、深入职业和导师匹配放在后续阶段，用户也明确暂不做 P2。材料没有提供的批准权重、预算、真实学校日期和商户合同保持待配置。真实需求成立、真实学校上线和实际运营效果不是本机自动测试的结论。

具体执行结果见 `evidence/annual-materials/ACCEPTANCE.md` 与相邻脱敏 JSON；实际转换内容及截图在私有附包。没有将旧 v0.5 的独立 Agent 接包结果当作新版追加验证。
