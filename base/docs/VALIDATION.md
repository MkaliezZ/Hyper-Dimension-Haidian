完整验证选择、前置条件、记录与打包门槛统一见 [开发手册第 9–11 节](../DEVELOPMENT-MANUAL.md#validation)。当前校园包 v0.8.3 为文档/打包更新，运行时沿用 v0.8.2，不能沿用早期“只有 JSON、尚无校园账号”的描述。

## 无需启动服务的检查

```sh
node tools/verify-docs.mjs
# 仅对原始解压包：
node tools/verify-package.mjs
```

## 开发副本的基线

按手册安装根与 admin 开发依赖后，执行 `npm run doctor`、`npm run build`、`npm test`、`npm run verify`。其中 `npm test` 不包含全部浏览器/live 脚本。浏览器另配置 `CHROME_PATH`；真实模型另需私有模型配置。服务测试须有全新隔离的 Ubuntu 栈、`HD_M0_CONFIG` 和脚本要求的 fixture 环境。先读各脚本的守卫，不把历史专用脚本当通用命令。

| 检查        | 实际含义                                 | 不能代替                        |
| ----------- | ---------------------------------------- | ------------------------------- |
| 文档        | 入口、路径、锚点、版本/角色索引          | 运行时已执行                    |
| 单元/契约   | 协议、几何、权限与模块规则               | 原生服务或实际模型              |
| 浏览器      | 独立上下文实际界面操作、模型加载与交互   | 真人或物理多设备                |
| A2A         | SDK/进程、能力与当前委托、重复/撤权/恢复 | 所有第三方 Agent 或公网环境兼容 |
| 真实 Hermes | 实际模型、隔离/追问/刷新恢复、引用及删除 | 离线模型或广泛事实保证          |
| 备份恢复    | 完整清单、七库与文件、独立目标对账       | 目标域名与正式客户端切换        |
| 归档        | CRC、逐文件/整包SHA、解压校验及相应冒烟  | 真实学校正式上线                |

本版记录：[文档与打包验收](../evidence/documentation/ACCEPTANCE.md)。继承的实际 Ubuntu/Hermes 运行证据：[v0.8.2 验收](../evidence/ubuntu-hermes/ACCEPTANCE.md)。其他历史记录保留原版本与失败说明，不能直接拼成新版“全部通过”。
