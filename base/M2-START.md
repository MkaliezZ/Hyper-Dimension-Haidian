# M2 v0.4.0 · 校园人物与轻互动

> **历史范围 / 兼容工具参考。** 本文记录当时里程碑，不是当前完成度或开发优先级。旧的“尚未实现”、功能上限、数据库数量及候选状态不覆盖后续版本；涉及具体命令仍须核对当前脚本和实例。当前流程以[统一开发手册](DEVELOPMENT-MANUAL.md)及本版验收为准。

本包接续 M1 v0.3.0，独立于原游戏。人物、背包及私人收藏使用学校账号和服务器 PostgreSQL；前端为浏览器。启动完整账号版需要 Ubuntu 服务环境，单独 `npm start` 仍是 Base-1 空间示例，不会启动完整 M2。

1. Agent 先读 AGENTS.md、本文、[M2 使用与接口](docs/M2.md)、[20分钟验收卡](evidence/m2/ACCEPTANCE.md)。
2. 新服务器按 docs/M2.md 初始化；已有 M1 先完整备份，再恢复到新实例升级。不要对原库直接演示、造测试数据或重置。
3. 登录 `/m1.html`，点“人物与空间”进入 `/m2.html`。选择人物部件、肤色、性别表现和颜色并保存，再领取背包，进入学校空间使用。
4. 旧人物会显示“迁移并保存”。确认前继续保留旧人物；确认后新增 M2 存档和历史，不改写旧表。
5. 图纸、学校资料、美术与 Hermes/知识库的 Agent 流程继续使用原来的 AGENT-START.md、prompts/00-BUILD-SCHOOL.md 和相关文档。人物库扩展另读 prompts/05-AVATAR-LIBRARY.md。

## 包内增加的内容

- `assets/avatars/`：24个原创 MIT 部件、4个预设、统一骨架目录、SHA-256、许可证。
- `src/avatar/*-m2.mjs`：确定性人物配方、组合校验、VRM 1/GLB 原创模型生成器。
- `src/platform/m2.mjs`、`database/m2-001.sql`：服务端版本控制、历史、背包发放/装备/扣减、私人收藏、名片可见范围。
- `public/m2.*`、`public/scene-tools.js`：捏人工作室、背包与空间道具入口。
- `tools/m2-init.mjs`、`tools/m2-assets.mjs`、`tests/m2*`：初始化、素材再生成与可复做验收。
- `evidence/m2/`：本版本自动验证证据；不含用户库、账号密码或原图纸。

## 当前范围

完成本轮优先的人物与部件库、捏人到存档恢复、背包及非破坏性轻道具。附基本学校名片与接待入口。挥手仅在本人画面显示；明信片是可下载的地点纪念插画，非场景截图。没有增加小游戏、交易、积分奖励、多人同步人物或 Agent 长期记忆。M3/M4运营与合作方业务仍按后续规划推进。

M1的账号、组织、私信/讨论、论坛审核与编辑、事件对账和备份入口继续保留。生产部署的 TLS、真实邮件送达、容量及学校用户验收需在目标服务器执行；本包证据是同机 WSL Ubuntu 与独立 QA Chrome 的自动验证。
