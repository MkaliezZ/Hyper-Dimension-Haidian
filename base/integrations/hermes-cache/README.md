# 可选Hermes依赖下载缓存

本目录默认只有说明，首次安装仍按固定Hermes源码与原uv.lock冻结安装。部署维护者可把自己在相同固定Python镜像、uv版本和上游锁下生成的公开依赖缓存临时放到 `uv/`，供后续镜像构建复用。只使用可信的本机构建缓存，不接受来源不明的缓存。

`deploy/Dockerfile.hermes` 支持该缓存，仍验证Hermes源码SHA-256、固定uv轮子及冻结依赖锁。先在缓存目录为空时构建核心镜像，再临时提供缓存构建Hermes层，避免旧构建器把缓存带进核心镜像。缓存不含模型密钥、用户配置、对话、运行数据库或学校项目，通用ZIP也不收录它，最终Hermes运行层不复制它。用完由部署端清理，不把构建缓存当成用户数据备份。
