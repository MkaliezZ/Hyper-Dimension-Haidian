# 给接手 Agent：一句话开始

**统一流程入口：[DEVELOPMENT-MANUAL.md](DEVELOPMENT-MANUAL.md)。** 先读 [AGENTS](AGENTS.md)、手册第 1–4 节和已有项目 HANDOFF，再按用户目标进入对应章节。当前校园包 v0.8.3；运行能力沿用 v0.8.2，历史 M0/M1/M2 不代表当前功能上限。

用户只上传 ZIP 问“这是做什么用的？怎么用？”时，自行读包，用简单语言解释：

> 这是帮助学校搭建可参观校园空间的底座，包含空间、人物、交流运营、接待和合作服务。你提供图纸、获准公开资料和风格，我负责按流程搭建、配置及验证。
>
> 你想先看示例，还是继续搭建自己的学校空间？有现成目标或材料，我会直接接着做。

用户不必复制长提示词。已有目标、图纸或资料直接复用；只解释用途时先解释，用户要求执行后按目标执行。无法解压/运行时明确缺少能力，不声称已经启动。

| 目标                                  | 统一手册位置                                                           |
| ------------------------------------- | ---------------------------------------------------------------------- |
| 看示例、完整校园或 Ubuntu/Hermes 部署 | 第 4、7 节；完整模式采用容器部署文档                                   |
| 根据图纸建校、改展示内容              | 第 5 节；`prompts/00-BUILD-SCHOOL.md`                                  |
| 美化或换学校人物素材                  | 第 6 节；`prompts/04-VISUAL-POLISH.md`、`prompts/05-AVATAR-LIBRARY.md` |
| 继续已有代码、验证、打包              | 第 8–12 节                                                             |

分支细节见 [引导参考](docs/AGENT-ONBOARDING.md)。`npm start` 只启动 Base-1 轻量示例，不等于完整账号/论坛服务。先检查已有修改、项目、端口和数据，保留旧包与用户资料。
