# 海淀校区建筑外形核对与重建

2026-11-06 用户要求：地图各栋建筑尽量接近实景，重点纠正中华文化园亭廊的方盒子外形。

本轮采用原有 UW 斜视投影、三角面栅格化、颜色/深度分块和选中接口。建筑由代码生成真实几何面，不把照片贴在地图上，也不使用生成图代替实景核对。逐栋记录多个具名全景观察点和能看清的立面、层数、屋顶、入口、曲面及材料；没有外景依据的附属楼保持明确的低置信度，不杜撰校方事实。

先核对来源并记录体量特征，再把每栋的体块、屋面和细部写入学校专属建筑配置。亭廊采用开放柱架、石台阶/栏杆、中式坡屋顶及翘角；图书馆和南岸弧形立面、宿舍红砖/楼梯竖带、食堂坡屋面/玻璃入口、膜结构弧形轮廓分别建模。

同一份建筑配置生成可见几何、地面实体/柱体、通行面和总图轮廓，避免只改颜色。轮廓或内容变化后统一重建颜色与深度、图鉴、几何指纹和路线验证。保留建筑稳定 ID、Base、后台功能、人物、照片及已封存交付。修改前快照见本机 `.local/history/20261107-architecture/`。

布局仍以2018公开示意为基础，不把照片推定的尺寸声明为测量值。对照图属于视觉核对证据，技术绿灯不替代外观检查。

## 几何与碰撞

- 红砖宿舍采用平顶、层高/窗格、金属竖带及柱式门廊；N3门廊收窄并朝北，N6主入口玻璃面朝东，朝向根据总览与观察点相对关系推定。
- 图书馆为红砖圆弧端头；S5/S6/S7采用三层浅石材弧面、窗带、玻璃入口和薄挑檐；S4降低为低层长条。
- 食堂与体育楼使用深色折坡屋面及屋面小窗，南岸食堂另有玻璃中厅和前凸门厅；气膜场馆是完整弧壳和圆钝端部，不再立在高层窗格盒体上。
- 亭廊为红柱、彩绘梁、灰瓦翘檐、屋脊、侧翼连廊、石台与阶梯。没有封闭红砖墙，柱体/栏杆分别阻挡，平台与入口可行走。旧亭廊示意矩形部分压入河道，本轮将这一非测绘点位移到相邻文化园岸上；不可据此宣称校方认可的精确位置。
- 渲染面、碰撞体、通行面、北向小地图及阴影来自同一份解析后的建筑构件。颜色、深度、33张地点图鉴和内容指纹同步重建。扫掠检查增加几何边界相交处理，防止路径重采样擦过弧面、柱子或凹入的校园边角。

## 当前仍需外景核对

N7目前只有高中教室内景；N12、S3、S3-A、S10尚无可靠可定位外景。上述5张建筑卡标明“外形待核”，未把其他楼的立面当作已确认实物。N5/N6翼部和体育馆/泳馆独立外墙有局部或楼群依据，完整背面及细部仍未测绘。

## 本轮验证与文件

- `npm run build`：66条往返路线、28个颜色/深度文件检查通过。
- `npm test`：41项回归；包含柱廊通行、柱体阻挡、圆弧/气膜几何、数据清单一致和26个建筑深度所有者可见。
- `npm run review:architecture`：按生产网格、材质和深度引擎渲染26栋×4向，共104张检查图。旋转模型不代表照片已做相机标定，也不增加地图运行时的旋转功能。
- `evidence/haidian/architecture/browser-buildings.json`：真实6290实例逐张打开26栋卡片，5栋有明确外形待核状态。
- `evidence/haidian/architecture/*-browser.jpg`与`pavilion-before.jpg`、`pavilion-after.jpg`：真实页面截图；`views/`下为四向网格检查图。
- `data/haidian-architecture.json`是人工核对的体量配置，`public/haidian-architecture.js`将它解析为共享构件，`src/haidian-buildings.mjs`生成几何面，`src/haidian-shader.mjs`生成像素材质。
- Base的538个上游文件、人物配方、权限、A2A、社区和学校数据隔离保持原有实现；本轮只改学校数据、美术和共享步行几何判定。
