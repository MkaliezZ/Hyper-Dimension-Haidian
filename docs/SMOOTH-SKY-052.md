# UW v0.5.2 平滑行走、天空与校园边界

## 使用

仍用 WASD / 方向键或屏幕按钮移动，松开停下；拖动旋转视角。人物立即按帧响应输入，网络回包用于柔和校正，刷新后从服务器存档恢复。校园外沿用绿篱围合；碰到边缘后向外分量被阻挡，可以沿边缘走。蓝天、柔白云及既有 Rainier 远景为场景美术，不表示实时天气。

体验边界来自本 MVP 的已建模校园矩形范围，内缩 2 米并保留人物半径 0.38 米；不是 UW 产权边界或开放通行声明。原 GIS、地形、建筑、地标和 81 对公共路线没有改写，既有路线检查未越出该范围。渲染与服务端碰撞使用同一 explorationBounds 函数，不靠前端隐藏按钮阻挡。

## 改动

- public/visitor-camera.js：一次性构建按平面格子划分的三角形索引，共享原几何位置和材质，不渲染索引网格；射线只查附近格子，保留楼体、装饰、材质面向和实例变换的遮挡结果。
- public/walk-motion.js：仅管理展示位置的逐帧预测、150ms 软校正和 500ms 无回包预测上限；不提交坐标、不授予到达权限、不更改服务器事务或得分。校正小于微米时清零，停止后不持续漂移。
- public/visitor-walk.js：方向立即发布给展示层；续发周期按发送开始计算，避免把网络等待再叠到 220ms 周期上；服务器请求仍串行、带版本和幂等 ID。镜头自动避让不自行改变按住时的移动方向，用户旋转视角后重新定向。
- public/app.js：缓存静态校园阴影，人物使用随身接触阴影；减少重复文字写入和布局读取，平滑转向及镜头跟随，校准服务器时钟时考虑往返时间。人物和操控就绪后才结束加载。
- public/campus-environment.js：原创渐变天空、太阳柔光和 12 组白云（48 个实例合成一次绘制）；绿篱和立柱标识体验边界。天空、云和两组边界合计 4 个绘制对象，不加入照片或商业游戏素材。
- public/campus-walking.js：同一边界参与服务器步进碰撞及客户端展示预测，返回 boundaryBlocked 供界面提示；对角移动在边缘滑行，不跨出去。
