# v0.11.3 · 本人 A2A 任务工作台

当前开发入口为本文件、[45项功能对照](BASE-FEATURE-AUDIT-20261102.md)及[任务工作台说明](A2A-TASK-WORKBENCH.md)。四个 Base 的现有业务接入保留；本轮补齐用户查看 Agent 执行进度、取回回执和停止未完成任务的统一入口。

校园服务 Base-1、Agent 目录、NPC 对话面板均提供“我的 A2A 任务”。目录来自当前授权的 catalog，支持学校、Agent、状态筛选及20条分页。列表只读元数据，选择任务后读取当前结果；导出前重新检查权限并读取最新回执。停止操作需本人确认；合作工单的业务撤销仍在合作服务处理。

前端复用原有 A2A 1.0 JSON-RPC 的 ListTasks、GetTask、CancelTask。未新增任务库、协议、模型调用、管理员代读权限或定时刷新。学校标识使用服务端显式 schoolId，不从名称推断。新入口沿用原生学校登录、同站返回和现有账号/学校/Agent隔离。
