## 补齐的两处交付缺口

1. 原有海淀常规回归只运行43项。一些保留的UW测试写死旧地标/学校ID，因而未纳入海淀命令。新增6组海淀适配套件，并补回2组通用套件，增加24项，现为67/67通过。原UW测试不改写成海淀历史结果。
2. 先前本地源码清单包含145个证据文件，而Git只保留其中README；直接保存Git会导致新克隆校验缺文件。默认打包现与Git排除规则一致，本地完整证据和旧ZIP保留；Git内仅保存公开的对照摘要。

新增回归覆盖服务错误学校/撤权/角色/禁用模块、目录授权、地点与背包到达边界、NPC事实与私聊分离、日预算/预留、站点迁移、会话幂等/重启/隔离/导出删除、形象存档兼容和官方A2A SDK。使用独立合成数据目录/模拟模型，不触发付费推理。此前已执行的真实模型问答不因增加这些测试而另称重跑。

## 复核

```sh
npm --prefix base ci --ignore-scripts --no-audit --no-fund
npm test
npm run build
npm run verify
python scripts/audit-uw-parity.py
node scripts/verify-source.mjs
```

`audit-uw-parity.py`默认仅做源码/契约检查，输出`SOURCE_PASS`。本次使用原有`check-haidian-services.mjs`在海淀虚构验收实例进行只读OIDC/入口检查，脱敏后以`--native-check <本地摘要文件>`合并真实结果；没有读出账号凭据、Cookie、任务正文或用户聊天。

当前海淀校园的33个地点/26栋建筑与UW的77个地点/74栋建筑属于内容替换。海淀历史总览、推定尺寸和缺少可靠照片的范围继续如实标明。真实学校账号/SSO、域名/HTTPS、SMTP、商户履约、规模压测及实际师生验收两版都需要各自正式接入，不在本次功能一致性结论中。
