# UW v0.5.0 界面与圆润人物

这是 UW 学校项目的本次更新，封存的 Base v0.8.3、UW v0.4.0 和用户数据保留。后端仍面向 Ubuntu，前端为浏览器；不新增外部模型服务、付费素材或网页追踪。

## 界面

- 地标详情放入侧栏，可展开/收起，不再覆盖校园主体；列表自动保持所选地标可见。
- 简化顶栏、提高正文与控件可读性，景观镜头集中在工具条。接待、资料、校园服务与导览入口保留。
- 人物编辑器为大预览、可滚动衣橱、固定保存栏；窄屏上下布局。衣橱卡片由实际 3D 配方即时生成缩略图，只有一个预览 WebGLRenderer，未为每个部件创建渲染器。
- 提供全身/细节视角、站立/行走/挥手、预设搭配、肤色/配色/身高。未保存与不兼容搭配有明确提示，保存失败保留草稿。
- 编辑器打开时暂停背后的校园绘制，关闭时释放编辑器网格、材质、渲染目标与接触阴影纹理，并停止动画循环。

## 人物方向与来源

参考用户提出的生活模拟卡通类型，采用原创圆润大头短身、可读五官、柔和发型、短四肢、圆鞋及布料轮廓。没有下载、复制或分发商业游戏的角色模型、贴图或标识。校园建筑和景观继续采用折纸风，人物按本次要求使用圆润卡通风。

仍然只有 7 槽、38 个简单搭配部件，不扩展精细捏脸。38 部件逐项构建和实际几何去重检查通过，单项测试配方最多 26,196 个三角形，当前检查预算为 30,000。保留旧折纸部件 6,500 三角形预算验证。网格预算不是帧率或服务器承载保证。

GET /api/avatar 的 profile 仍是原始存档；新增 presentation 字段按同一搭配产生当前外观，不写数据库。presentation.savedModelHash 指向原始存档，modelHash 是展示外观摘要。前端分别记录存档与显示摘要，不把新展示说成数据迁移。点击保存才将当前配方写入版本 3，并将此前存档保留到本人隔离历史。上一套搭配操作读取旧部件/配色，在当前造型中试穿；保存后才生效。两个旧生成器文件必须保留，不得当作无用历史删除。

## 续改入口

- public/visitor-chibi-model.js：原创人物体量、五官、发型、服装和动作；封装后若再次改变生成器语义，应新增版本并保留旧渲染器。
- public/visitor-editor.js / visitor.css：编辑器、缩略图与资源释放。
- public/ui-refresh.css / index.html / app.js：校园主界面、侧栏、接待面板与地图操作。
- src/visitor-avatar.mjs：受控目录、旧配方、只读展示和存档历史。
- tests/visitor.test.mjs：几何/比例/动作、旧版重现、隔离、CAS、只读展示不改存档和保存恢复。

## 验证边界

本轮功能自动检查与浏览器视口检查在 evidence/ui-avatar-050；浏览器使用独立虚构访客，未把用户当前真实会话放进截图。桌面 1280×720 和手机 390×844 为自动视口检查，不是真人或物理多设备验收。完整包解压启动记录随交付目录提供。
