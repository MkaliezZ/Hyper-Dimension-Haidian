# UW v0.9.0 · 统一场景、比例、遮挡与寻路

阅读顺序：README → AGENTS → 本文件 → DEPLOY-UW → base/DEVELOPMENT-MANUAL.md。v0.7/v0.8 的美术文档是历史依据，不再决定当前场景。现有 Base、旧交付、原用户数据与形象配方保留。

## 1. 当前场景规则

74 栋建筑共用真实地面轮廓、孔洞、统一米制投影、光照和材质。重点建筑不再作为一张整栋插画按外接框拉伸；建筑和平面图的地面比例均为 **1**。原 `.78/.39` 2:1 地面投影保留，对应 30° 正交视角；竖向高度系数为 `.78*sqrt(1.5)`，与同一视角相容。原始 GIS 文件、几何摘要、地标 ID 和学校/点位绑定不变。

源楼高继续标明 inferred。屋顶、门窗、石饰和分翼高度是美术推定，不作为实测立面、真实建筑入口或现状证明。Suzzallo 的主翼、附楼使用不同体量和立面模块；Denny 保留立于屋顶上的钟鼓与铜顶，全部控制在原推定高度预算内。角色仍为便于辨认的图标化形象，不把角色像素高度当作建筑测量标尺。

全校园使用同一套砂岩、红砖、板岩、石灰石与四类立面模块。源纹理先预滤，避免高频材质取单像素造成屋面噪点。地标卡片也从同一套几何/材质生成；旧整栋插画与街区图集保留用于历史，不在当前地图混用。素材提示词和来源见 ART-SOURCES-090.md。

树木/长椅采用官方点位快照；喷泉四组花坛、环道和通行开口详见 LANDSCAPE-090.md。

## 2. 遮挡和命中机制

离线度量几何通过软件栅格器烘焙为颜色块和逐像素深度块。浏览器继续使用 Canvas 2D，不启动旧 Three.js/WebGL 场景。深度缓冲决定每个像素最近的可见表面，绘制顺序不能改变建筑相互遮挡结果；不再用整栋楼的中心或最前边缘替代所有像素的深度。

同一组可见表面用于三件事：楼体与楼体/树木/设施之间的遮挡；人物每个像素的前后关系；鼠标命中真正看见的物体。庭院、透明区域和前景物体不会被外接矩形当成实心。被遮挡的角色只保留细轮廓与“楼后”提示，建筑本身保持不透明；未遮挡的部位正常显示。

点击反馈由 public/building-inspection.js 提供持续显示的建筑卡片；普通楼体显示已有名称和原始来源，重点地标接入原详情与步行功能。手机点击“查看详情”会展开详情栏。未命名楼体使用“校园建筑”，等待学校补充名称。public/surface-selection.js 从同一深度块的可见 owner 生成轻量高亮，遮在前面的树木、设施和其他楼体不染色；高亮沿用静态缓存，无需重新烘焙颜色/深度素材。

颜色和深度是不可拆分的一套资源。深度精度 1/64m，R/G 为有符号偏移深度，B 为块内物体编号，A 表示实体表面；块的 owners 字典还原全局物体 ID。全局编号支持至 65,535，不受一张 PNG 的 8 位编号限制。单块若超过 255 个可见物体则明确报错，需减小 tileSize 后重新生成，不可绕过校验。阴影为非实体，不进入碰撞或命中深度。

静态世界仍使用有余量的独立合成层和亚像素跟随。只在缩放、选择、路线、尺寸、专注状态改变或越过缓存边缘时重建。场景分块为 512 源像素，当前共 31 对颜色/深度块；缩放纹理按可见范围缓存并释放。dispose 解除监听、释放纹理和深度数组。人物遮罩在位置/动作变化时更新，静止时复用。

## 3. 安全寻路

当前原始公开步道图有 31 条边与楼体、水池或设施碰撞区相交。红场四台与方尖碑按多角度照片校准前，旧 v0.9.0 记录为 32 条。原始 GIS 保留，规划器给每条边做共享几何扫掠；不安全路段由 MIT javascript-astar 0.4.1 绕行，不能直接信任图上的连线。

- 优先使用公共步道图，连接不足时使用受控室外网格寻找连接或绕行；2m 网格，必要时 1m 回退。
- 默认最多 60,000/80,000 次搜索展开。网格禁止斜穿墙角；每个连接仍按与手动行走相同的 .38m 半径、.25m 扫掠、地形和边界复核。
- 路线从实际保存位置开始，不跳回附近节点；停止、继续、改目的地和刷新保持连续。
- 每段最终路线重新核验并约每米采样高度。封闭庭院、池内或墙内不会为了返回“成功”而制造穿墙路线；无连通路线时明确报错。
- 手动速度仍 6m/s，500ms 输入上限、归一化、服务器位置所有权、CAS、幂等、身份隔离和边界不变。导览演示速度仍 18m/s。

这不是实时道路开放或无障碍导航承诺；公开路径和源高度有时间差，真实入口须另外提供并核验。

## 4. 源码和续建

| 路径 | 用途 |
| --- | --- |
| src/coherent-buildings.mjs | 所有楼体的轮廓三角化、屋顶、分翼、钟鼓与建筑特征 |
| src/surface-raster.mjs | 共享材质采样、预滤、软件深度栅格与环境合成 |
| scripts/export-coherent-scene.mjs | 生成整套颜色/深度分块、物体绑定和同源卡片 |
| scripts/png-codec.mjs | 确定性 PNG 读写与 CRC 校验 |
| public/assets/coherent/ | 当前原图、分块、卡片、尺寸、源几何和 SHA 清单 |
| public/depth-scene-atlas.js | 浏览器加载、可见块 LOD、深度/命中采样和释放 |
| public/surface-depth.js | 与离线一致的投影深度、编解码和人物像素遮罩 |
| public/pixel-scene.js | 固定视角、缓存、场景/人物组合、点击、缩放与小地图 |

修改几何、材质、光照或投影后执行 `node scripts/export-coherent-scene.mjs`。禁止只替换颜色 PNG，沿用旧深度。旧人物生成器字节、rendererHash 和五代配方协议不在本版修改范围。

## 5. 验证和交付流程

1. 独立虚构运行目录验证编辑/保存/刷新、自由移动、导览/停止/续走、遮挡轮廓、可见表面点击和手机布局；不写用户形象或发送真实接待问题。
2. `node --test tests/*.test.mjs`：当前 69 项，包括交叉表面顺序无关、人物局部遮挡、孔洞、统一比例/材质、PNG CRC/SHA、全部 81 组路线的逐段碰撞复核，以及原 Base/身份/存档/API 回归。
3. `node scripts/verify.mjs` 检查源几何和数据；核对初始受保护文件、原用户集合和旧包摘要。旧测试把不安全源边中点当作可通行起点的部分已改为明确拒绝断言，不放宽碰撞来保留旧期望。
4. 生成新的完整 ZIP；CRC、所有载荷 SHA、私有数据排除检查后，在本地 WSL Ubuntu 全新解压，重新做 package/geometry、69 项测试、HTTP 资源和人物/步行保存重启。
5. 结果写入本版包外 HANDOFF 与 CURRENT-UW 指针。未通过全部必要检查时不封存为交付。

本机滚动帧数据是 CPU 提交和帧间隔采样，不是 GPU 耗时、所有设备固定 FPS 或服务器容量。浏览器检查不是客户/真实学生/物理多设备验收。原全栈/Hermes 9 项和恢复 8 项为继承证据，本轮没有重新调用模型或全套容器。

测试后关闭独立服务与浏览器标签，仅保留用户预览。旧包与 .local/uw-runtime 不删除；先前被自动审批拒绝的清理目标不换工具重试，记录实际手动路径。
