# UW v0.7.0 斜视像素校园开发手册

当前阅读顺序：README → AGENTS → 本文件 → DEPLOY-UW → base/DEVELOPMENT-MANUAL.md。旧 PIXEL-CAMPUS-060 和更早美术文档属于历史记录，不能当成当前视角限制。学校业务、Hermes、Protocol 和 A2A 使用既有 Base；本版只更新学校表现层和相关验证。

## 场景与素材

主场景使用 Canvas 2D：真实 GIS 地面经固定斜视变换，独立的透明建筑/喷泉/树木精灵叠放在地面锚点。六栋重点楼体（Denny、Raitt、Savery、Suzzallo、HUB、Kane）有照片或历史立面参考的原创像素素材；其余 68 栋按原始外轮廓生成像素墙面、窗带和屋面。公开照片是研究依据，不作为可分发纹理。素材是艺术概括，非测绘建模；体量和立面细节可能与现状不同。HUB、Kane 分别采用当前官方外观照片；不把 Kane 画成古典神庙。

Red Square 保留公开资料派生的不规则边界、砖纹和放射铺装，另加独立塔标与概括 Broken Obelisk。Drumheller 使用独立透明喷泉、花圃和水面闪点；树木、灯柱、长椅分别组合。未推断室内。背景的云、山和地平线是装饰，不扩大可活动范围。

地面按 **256×256 像素分块、边缘 1 像素重叠** 缓存；每帧只绘制可见块和可见精灵。建筑各自有约 1254px 的透明原图，环境使用独立图集，不把整个校园合成一张图片再无限放大。十二档缩放为 0.0625 / 0.09375 / 0.125 / 0.1875 / 0.25 / 0.375 / 0.5 / 0.75 / 1 / 1.25 / 1.5 / 2；关闭 Canvas 图像平滑，CSS 使用 pixelated，落点及精灵尺寸取整。最大 2 倍 backing 放大；继续放大会保持上限。像素风近看会出现有意的像素块，远看会减少细节，这不等于无限分辨率。

主场景北方在左上 N ↖。WASD 和方向键映射到屏幕方向，再转回原始世界坐标，斜向归一化保持原来的 4m/s。北向地图保留为可收起小地图；点击只移动相机，不移动人物、不发移动请求。

人物继续用相同 24×32、四向动作与 38 部件。按地面深度绘制建筑和道具；人物在墙后时按当前列的前沿和精灵透明遮罩遮挡，保留淡轮廓与脚边标记以便找到自己。建筑本体可点击，透明边缘不会误选。人物跟随、按键预测、服务器回执平滑和停止语义不变。

## 开发入口

| 模块 | 用途 |
| --- | --- |
| public/pixel-scene.js | 地面块裁剪、素材加载、建筑/环境组合、人物遮挡、点击、相机和小地图 |
| public/oblique-layout.js | 投影/逆投影、屏幕输入、建筑前沿、分块范围、离散缩放 |
| public/oblique-buildings.js | 以真实轮廓绘制次要建筑的二维像素立面；高度仍明确是推定值 |
| public/pixel-campus-art.js | 北向像素底图与道路，支持关闭楼顶/植物/道具后作为斜视地面 |
| public/assets/oblique/manifest.json | 8 张 PNG 的 SHA、原尺寸、透明裁剪、环境图集区域、提示词与来源 |
| docs/art-oblique-070/*.prompt.txt | 内置 image_gen.imagegen 实际使用的完整提示词 |
| public/pixel-avatar.js / pixel-editor.js | 沿用的部件人物、编辑与动作；不改变原生成器摘要 |
| campus-walking.js / visitor-walk.js / walk-motion.js | 原始碰撞、边界、短时方向请求和位置恢复 |
| tests/oblique.test.mjs | 投影、输入、遮挡前沿、缩放上限、块覆盖、素材与锚点验证 |

投影为 u=.78(x+z)、v=.39(z−x)，每米 2 backing 像素；逆变换只用于视角和输入。服务端仍使用原始 XYZ、真实路径和边界。74 栋轮廓、5 个庭院孔洞、400 节点/451 边、81 对路线及 geometryHash e77afd817acd8f7912598ec09feb7900329830c228580cfc593115a26a1dfe3d 不变。

扩展新楼体时：核对真实参考 → 生成同视角透明独立素材 → 将文件复制进 public/assets/oblique → 记录 SHA/裁剪/地面锚点/提示词 → 按楼体绑定 → 检查近远缩放、点击透明区、前后遮挡与边界。不要把外部照片直接塞进公开包，不要用图片轮廓替换真实碰撞。图像若覆盖邻楼、错位或裁掉底部，应修正绑定/素材，而不是放开碰撞掩盖问题。

## 存档、后端与交付

人物仍是 uw-visitors-4 / uw-pixel-1.0.0。pixel-avatar.js 和 pixel-raster.js 原字节保留，旧 v1–v3 兼容文件保留在 compat；GET 不迁移历史配方，显式保存才写新记录。保留私有 .local/uw-runtime、Hermes 配置、Cookie 身份和全栈数据库/卷。本版不复制真实用户会话到测试实例。

学校账号、权限、论坛、活动、背包、私信、历史索引、校友/学长/机会、合作方 A2A、接待会话与导出删除沿用原后端。未连接完整模式时明确显示未连接，不伪造可用。部署沿用 Ubuntu Docker 编排；本版新增的是公共 PNG 和 JS，无需变更数据库。

验证和打包：`node --test tests/*.test.mjs` → `node scripts/verify.mjs` → 隔离浏览器检查（桌面、窄屏、缩放、步行、图层遮挡、小地图）→ 审查差异/来源/用户数据摘要 → `python scripts/pack.py --out /new/version/complete.zip` → 从该 ZIP 全新解压验证全部 CRC/SHA → Ubuntu 运行相同测试和保存/重启 HTTP 检查 → 更新外部交付指针。新包不得覆盖旧 ZIP；运行数据、原照片/PDF、密钥和 QA 目录不得进入 ZIP。

当前版本实际执行结果见 evidence/oblique-070 与包外 HANDOFF。历史 v0.6.0 原生全栈/Hermes 9 项、备份恢复 8 项作为继承证据；仅当前前端变化时不把它们写成重跑。自动与浏览器检查不等于真实学生或生产校园验收。
