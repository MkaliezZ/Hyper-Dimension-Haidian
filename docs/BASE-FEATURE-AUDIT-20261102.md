# 四个 Base 功能对照与继续开发 · 2026-11-02

基线：2026-10-23 的45项规划，叠加用户后续范围调整；对象是当前 UW 学校副本 v0.11.3 及其保留的 Base v0.8.3。旧规划 CSV 的“待开发”是立项状态，当前实现以这份对照、源码和各版本验收为准。原规划、通用 Base 原件、用户材料和旧包保留。

39项 P0 和保留的3项 P1 均可定位到实现模块及已有验收。个人 Agent 长期记忆已从范围移除；地区/跨校社群与复杂订单交易两项 P2 继续暂缓。本轮新增的是 A2A 的用户任务工作台，补齐“接口能执行，用户也能查看进度和取回结果”的入口。

## 本轮新补齐

- 校园服务 Base-1、Agent 目录和 NPC 面板增加“我的 A2A 任务”。目录从当前授权的真实校园 catalog 读取接待、6位 NPC 和合作业务 Agent；学校 ID 使用服务端显式标识。
- 按 Agent、任务状态和分页读取本人记录；默认列表只取元数据，点击后读取当前回执。结果来源、模式、任务/上下文编号和时间可见，可显式导出。
- 停止未完成任务需要本人确认；结束任务显示最终状态，不自动发起新执行。合作工单的业务撤销继续使用合作服务。
- 当前账号/学校/Agent/撤权与会话保留规则沿用已有网关。没有另一套任务库，没有新增模型调用或自动刷新后台进程。
- 校园模块从22个增加至23个。原有地图、HUD防遮挡、人物速度与比例、业务页面、Hermes和DeepSeek配置保留。

## 验证口径与证据

本轮新增任务工作台的网关隔离、停止在途执行、分页、导出与浏览器操作在独立虚构环境检查；原生实例以真实 OIDC 和新建的本人只读路线任务验收。任务检查不触发付费模型、不移动人物、不读取已有私人对话。
原有全模块业务和五库恢复依据 `evidence/functional-acceptance-20261030/`、`evidence/full-base-v0100-20261030/`；本轮任务证据在 `evidence/a2a-workbench-20261102/`。原有各模块的验收时间和范围不改写成本轮重新执行。
通用业务逻辑、校园适配、编辑器与任务前端为自研；开源服务及其原许可证保留。DeepSeek 是配置的模型 API，不列为本项目开源实现；CharacterStudio、Casbin、SeaweedFS、Medusa 等候选没有作为已集成能力列入。

对应明细 CSV：`BASE-FEATURE-AUDIT-20261102.csv`。完整包、最终验证与当前指针以本轮包外 HANDOFF 为准。
