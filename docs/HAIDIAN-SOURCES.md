# 海淀校区资料与复原范围

本学校副本对应**北京市海淀外国语实验学校北京海淀校区，杏石口路20号**。用户已明确选择该校区。

事实：公开总览呈现北侧教学生活区、南岸教学区、南旱河、校园桥、东侧田径场等。地图保留这些相对关系。小学楼、宿舍、食堂、图书馆、实验楼、艺术楼、体育馆等名称与编号对应总览。

位置与尺寸推定：26个楼体的校园相对位置以历史示意为基础，约0.8米/总览像素为统一美术尺度。v1.1.0逐栋核对可见的多角度实拍，修正红砖/浅石色体量、平顶/折坡顶、弧面、气膜壳、入口与中式亭廊；没有照片的楼体和隐藏立面保留明确推定。亭廊旧示意矩形压入河道，已移到相邻文化园岸上，位置不作为精确测绘事实。铺装与122处种植为原创程序绘制。河道、边界与校园桥使用同一份多边形数据驱动地图和碰撞。未取得测量高程，地面明确采用平坦示意，不使用UW地形。

未知：当前所有楼名和用途、真实出入口、无障碍条件、施工与封闭信息、活动和正式运营规则尚未由校方逐项复核。接待只引用本版发布的资料，不编造这些信息。

像素美术使用原创代码生成素材。研究网页和未选用照片保留在本机忽略的`sources/`目录；v1.0.1新增27张经过核对的官方海淀校区实景原图，放在`public/assets/place-photos/haidian-*.jpg`，逐一保留原场景链接、发布署名、原作者保留权利说明、尺寸和SHA-256。地点卡不显示UW照片。UW旧美术素材是上游兼容记录，不是当前场景。所有当前分块与图鉴由`public/assets/coherent/manifest.json`明确引用。

修改布局：编辑`scripts/prepare-haidian-data.mjs`，运行`npm run build`。同轮生成校园数据、接待资料、景观、颜色/深度分块和图鉴。不要单独改图片而保留旧碰撞或哈希。

v1.1.0的逐栋来源、82张实拍视图记录、造型修改和未核范围见[建筑外形核对与重建](HAIDIAN-ARCHITECTURE.md)。修改体量配置后仍须统一重建颜色/深度、碰撞和来源指纹。
