# v0.10.1 · 前端 UI 检查与地标留言修复

本版沿用 v0.10 的四个 Base、账号/组织权限、Hermes、数据模型和校园几何，修复学校 UI。v0.10.0 封存包保留，当前源码版本为 0.10.1。

## 功能修复

- 从地图进入社区时，筛选与写作表单同步关联已验证的学校地标；明确显示地标名称、写留言入口和全校社区入口。
- 未登录显示中文说明；同一标签内登录后返回原地标，只记录短时页面路径。公开参观仍可直接使用。
- 提交自动保存草稿并送审，处理中防止重复点击。自己的投稿有查看入口，刷新可恢复详情。
- 评论明确关联原帖与地标，编辑器获得焦点，审核后可返回原帖查看。编辑已发布正文使用现有原生编辑页。
- 通过现有 M0 论坛 posting-state 契约读取真实发帖间隔，展示倒计时并保留保存草稿功能；不降低限制。M1 的同名后缀实际返回帖子列表，不能当作计时契约。
- 请求失败保留文字和可重试状态；已保存草稿及附件可在刷新后继续。
- 原生业务页面使用 campus-native.css；地图 pixel-ui.css 独立，修复筛选布局、窄屏品牌和复选框被地图规则影响的问题。字号、触控尺寸和键盘焦点统一。
- 奖励工作台切换时暂时禁用相关入口，避免忙碌期间点击新建被静默忽略。弹窗补齐可访问名称，关闭后回到触发按钮。

## 本轮验证

证据在 evidence/ui-audit-20261030/：22 个模块桌面/390px 共 44 个页面状态、10 个标签和管理折叠区；6 条实际浏览器链路；活动/奖励两条弹窗检查。真实 Keycloak、NodeBB、PostgreSQL 等运行于独立虚构 QA 实例，所有测试投稿/评论/附件留在该实例。80 项回归通过。前后截图与逐项清单见同目录 UI-AUDIT.md。

早期失败尝试保留：邀请测试曾误加不支持字段；初次测试使用的 M1 posting-state 不是计时端点；重复标题导致测试选择器不唯一；重复投稿测试触发真实论坛冷却。修复使用正确契约和唯一测试标题，故障保留测试改走保存草稿，不改断言或生产限制。额外弹窗检查发现并修复奖励工作台忙碌入口和焦点问题。

未重跑本版无变更的 86 项完整后端业务/全库恢复；其来源仍是 v0.10.0。当前运行、完整新包、归档校验及最终 QA 清理以外部 v0.10.1/HANDOFF.md 为准。学校源码中的 Base/public 原件与封存 Base 清单未改。
