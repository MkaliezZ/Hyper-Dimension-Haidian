# UW辨识度：功能首版与后续美术的共同约束

最新方向：先打通功能，美术随后细化。2.5D是表达方式，不是降低素材要求的理由。

## 首版必须保留

| 校园特征 | 当前依据与表达 | 美术阶段必须深化 |
| --- | --- | --- |
| Denny Hall | 官方名称/位置、2023轮廓；1895历史、法国文艺复兴复兴式与穹顶参考；概念化顶部标识 | 查阅足够的现状立面/许可照片；专属屋顶、穹顶、轮廓与材质，不能靠通用欧式楼替代 |
| The Quad 与周边 | Raitt/Savery及相邻建筑的真实围合；Quad地图校准位置 | 核实方庭轴线、樱花树阵、路径和季节表达；树木不能只随机撒点，不把概念春景称实时花期 |
| Red Square / Suzzallo | 真实相邻轮廓与地图名称；红色铺地概念表达 | 校核铺地边界、哥特式主立面、入口、尺度、导视和广场空间；不能用普通图书馆盒子替代 |
| Drumheller / Rainier Vista | 地图核对喷泉与景观关系，真实坡地；水池为概念模型 | 精确场地轴线、视廊、地形、铺地和植被；不得虚构实时能见度或山景 |
| HUB | 官方HUB建筑身份、轮廓与学生中心历史资料；功能入口 | 现状外观、入口与学生生活信息；活动及负责人权限须接既有Base服务 |

目前只把位置、轮廓、来源和交互接通。占位窗格、植被、推定高度与概念屋顶不是最终美术交付。

## 后续验收

1. 对照UW官方地图和获准现状参考，列出每个重点建筑的轮廓、立面、标志性构件、材质与未知项。
2. 先做 Denny / Quad / Red Square–Suzzallo 三个代表场景，取得方向确认后扩展。
3. 为每项学校素材登记作者、来源、许可、版本和摘要；2D设计稿不能当成3D适配完成。
4. 替换后继续共用米制坐标、地形、实体ID与导航数据，核对遮挡、点位点击、路径、性能和无障碍UI。
5. 用完整校园视图和近景前后对比验收UW可辨识特征；界面有“UW”文字不算建筑和场景完成。

没有使用2019规划图把未建方案当现状；没有声称测得建筑高度、精确BIM、室内、实时开放、实体设备或UW官方验收。
