# v0.10.3 · 全功能操作验收与奖励到期显示

本版依据 Base 1–4 的22个现有功能模块进行浏览器操作与真实后端验证。结果和截图在 evidence/functional-acceptance-20261030/；最终交付、运行版本及备份恢复结果以包外 HANDOFF.md 为准。

本次修复学校副本 personal.mjs：奖励徽章到期后，后台回收底层权益会记录 revoked；页面此前只对尚未回收的 active 徽章显示“已到期”，因此后台处理速度会影响显示结果。现以有效截止时间和回收发生时间区分自然到期与提前撤销，使到期前后显示保持一致。到期前的人工撤销仍显示撤销，不恢复任何权益，不改贡献或库存规则。

窄屏检查还发现 Agent 卡片中的连续长名称会撑宽页面。学校业务卡片现允许在长单词内换行，卡片可以收缩到可用宽度；不截断服务名称和操作入口。

登录沿用 v0.10.2 的服务端续期。校园几何、人物存档、角色权限、Hermes、已有 Base 功能和所有旧交付包保留。通用 Base 原仓库及原封存清单没有修改。
