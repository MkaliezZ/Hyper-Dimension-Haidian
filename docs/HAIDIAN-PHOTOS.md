## 维护与复现

- `data/haidian-place-photos.json`：人工核对后的唯一登记，保存场景、面方向、卡片匹配依据、原图URL、尺寸、SHA-256和待补原因。
- `public/assets/place-photos/manifest.json`：由`python scripts/publish-haidian-photos.py`离线生成，沿用UW组件字段；照片随本地源码提供。
- `python scripts/publish-haidian-photos.py --download`：仅维护时从登记的原始URL恢复照片，哈希或尺寸不同立即拒绝，需重新核对。日常浏览不依赖远程图片服务。
- `scripts/research-haidian-photos.py`：研究用，读取本机`sources/haidian-photos-20261106`中的官网全景公开页面与元数据缓存；不属于构建依赖。
- `npm run build`：不会覆盖或清空已审核的照片清单。`npm test`验证所有地点状态、场景来源、文件原始哈希与尺寸。

## 本轮验证

- 36/36安全、行为和照片完整性回归通过；完整构建与66条路线验证通过。
- 真实6290实例的33张详情卡逐一打开，29张显示照片来源，4张显示具体待补原因；全部27张本地图像通过HTTP读取并核对原图哈希。
- 桌面1280×720、手机390×844实测，照片、图注、来源和原有卡片操作可见。证据：`evidence/haidian/photos/browser-cards.json`、`swimming-card-desktop.jpg`、`swimming-card-mobile.jpg`。
