# UW v0.5.1 人物可见性与自由漫游

本文件是 v0.5.1 行为快照。当前的平滑展示、空间索引、天空和绿篱边界见 SMOOTH-SKY-052.md；服务器的位置所有权和隔离规则继续适用。

## 怎么用

进入页面后默认跟随当前人物；首次访客可先保存或关闭人物编辑器。按住 WASD 或方向键移动，松开停下；屏幕方向按钮支持按住和轻点，手机也可操作。方向相对于当前镜头。拖动地图旋转视角，滚轮缩放。“找到我”回到人物近景；右上角房屋按钮切换校园全景。输入接待问题、搜索、编辑人物时不触发移动。新版不自动改写旧人物配方或旧位置。

地图的地标步行导览仍可使用。手动方向会接管当前导览；停止后从当前位置续走，无需先选建筑。开始地标步行时保持人物镜头；完整路径可通过全景查看。自由位置只在存在无遮挡连接时接入附近公共步道；无连接时提示先走近步道，不穿楼抄近路。

## 实现与约束

- public/visitor-walk.js：键盘/触控输入、短按、松开/失焦停止、串行请求及冲突同步。即使响应晚于短按结束，仍发送停止。
- public/campus-walking.js：前后端共用地形高度与步进碰撞；模拟水平速度 4 米/秒、半径 0.38 米。建筑实体保留庭院孔洞，穿墙与水池越界阻止；小步连续检测，避免跳过薄墙。公共步道/广场的视觉面层用于脚底高度。
- public/campus-layout.js：与既有景观共用红场和喷泉几何常量；未改原 GIS 数据、DEM、81 对地标网络或封存 Base。
- public/visitor-camera.js：近楼优先选择通畅环绕角度；建筑壳、装饰立面均参与镜头检查。镜头碰撞最多每 100ms 检查一次，人物动画与位置仍逐帧更新。
- POST /api/walk：仅接收方向、50–500ms 时长、预期位置版本和请求 ID；位置由服务器从当前时间计算，不接受目标坐标/他人身份。幂等回执、CAS 与签名访客/学校账号隔离沿用原存储。重复高频指令不能把未来端点当作起点累积加速；断线后最后指令最多 500ms 自动结束。
- POST /api/move/stop：可携带位置版本，防止旧页面覆盖其他页面的新移动；旧调用保留兼容。GET /api/me 返回权威位置和移动状态。

这是虚拟空间的移动边界，不是道路通行、实时开放或无障碍保证。装饰和高度仍有简化，人物没有跳跃、破坏或进入未建模室内的权限。

evidence/walking-051 记录隔离虚构访客的浏览器检查与本轮自动测试。新增检查包括短按延迟停止、近墙镜头、建筑/水池/边界与对角限速、无遮挡接回导览、HTTP 防伪造/CAS/重放/身份隔离/重启恢复。旧人物、A2A、接待、导航与建筑接地检查继续运行。

新完整 ZIP 的 CRC、全部文件摘要和全新 WSL Ubuntu 解压启动、移动保存/恢复在对应交付目录单独记录。本轮不重新运行真实 Hermes 模型或全栈容器验收，不以自动视口检查代替真人或物理设备验收。
