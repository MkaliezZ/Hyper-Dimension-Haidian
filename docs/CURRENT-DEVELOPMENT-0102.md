# v0.10.2 · 浏览器登录自动续期

学校页面登录后，浏览器保存一小时的 HttpOnly 会话 Cookie。旧实现却把数据库会话截止时间缩短到身份令牌的五分钟有效期，也没有保存续期凭据；超过五分钟刷新页面便退回访客。

本版在服务端保存 OIDC refresh token，按需更新已过期的短期 access token。一小时内刷新、切换校园业务页面和并发请求继续使用同一身份。浏览器只保存不透明的会话 Cookie，凭据不写入 localStorage。会话总时长仍是一小时，从首次登录计时；没有改成长时间永久登录。

更新前的会话缺少续期凭据，需要重新登录一次。账号、UW 学校归属、角色、人物、背包、投稿及原访客存档继续保留。公开参观模式仍可直接进入。

## 实现与边界

- 仅学校副本 base/src/platform/identity.mjs 与新增 browser-sessions.mjs 变更；原封存 Base、旧交付包保持原状。
- 新增 hd_session_refresh 表，外键关联 hd_sessions，退出删除会话时一并删除续期记录。首次使用自动建表；现有业务表与用户数据不重置。数据库备份应继续包含整个应用数据库，包括此表。
- 仅凭真实令牌过期触发续期；普通拒绝、停用账号、学校撤权继续由原权限检查处理。外部 Agent 的 Bearer token 仍按自身到期时间拒绝访问。
- 每个会话使用数据库行锁串行处理刷新令牌轮换；新令牌须保持相同发行方和账号。身份服务短暂不可用返回可重试错误，保存已完成的轮换结果。
- 不增加依赖，不改 Hermes、校园几何、人物、论坛审核和学校/组织权限规则。
