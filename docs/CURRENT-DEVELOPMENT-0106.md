# v0.10.6 · 全楼体地点功能与实景照片

入口为根 README。地点目录由 public/campus-places.js 从原始校园数据派生：74 栋建筑各自一个稳定实体，加 Quad、Red Square 和喷泉，共 77 个地点。原九个地标实体不改名，既有留言继续关联原地点。未命名轮廓以公开对象编号区分，不推测名称。

所有建筑支持详情、接待、地点留言与记忆、社区活动、背包和其他已启用的校园功能；学校成员、审核、角色与到达距离约束继续由原后端检查。新增地点导览使用共享碰撞检查的室外靠近点，非室内入口。源码不更改 campus.json 的几何、烘焙资源、人物存档或 Base 模块。

真实照片的离线清单、摄影者、许可证、来源与 SHA-256 位于 public/assets/place-photos/manifest.json。place-photo.js 按地点准确选择本地照片，正常图像采样，不用像素插画冒充实景。无可靠照片的地点不渲染照片区域、文案或替代图；下载错误同样移除图片区域。像素图鉴与地图美术仍是原先的独立展示。

查证与发布工具为 scripts/prepare-place-photos.py 和 scripts/publish-place-photos.py，需 Python Pillow 和网络，仅离线显式运行。已发布照片随包附带，启动与浏览无须外网请求。增补照片后更新来源、许可及哈希，并检查实物匹配。照片本身沿用逐文件许可，学校代码的许可不覆盖它们。

自动化验收与实际隔离环境浏览器操作见 evidence/real-photos-20261030，最终运行、交付包和保留状态以新版本外部 HANDOFF 为准。

实际收录 41 张实景照片：36 栋建筑、3 处户外地标、红场两处细部。77 个地点卡及服务绑定已逐一检查。地图介绍统一采用自然的校园文案；建模/数据细节集中在资料面板及开发文档。
